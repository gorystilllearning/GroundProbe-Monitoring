# GroundProbe-Monitoring
This repository contains the deployment scripts, Docker configurations, and environment setups for implementing Zabbix Monitoring System tailored for GroundProbe Slope Stability Radar (SSR) Wireless Communications.
# 📊 GroundProbe Zabbix Monitoring Installer

An automated, single-click deployment package for Zabbix Server 6.4, pre-configured with a custom Premium Dark Glass theme and corporate branding.

## 🚀 Installation Guide

### For Windows Users:
1. Ensure **Docker Desktop** is installed and currently running.
2. Download or clone this repository into a single folder.
3. Double-click the `setup.bat` file.
4. Wait for the terminal process to finish and close automatically.

### For Mac / Linux Users:
1. Open your terminal and navigate to this repository's folder.
2. Make the script executable by running: `chmod +x setup.sh`
3. Execute the installer by running: `bash setup.sh`

## 🌐 Dashboard Access
Once the installation is complete, open your web browser and navigate to:
👉 **http://localhost:8080**

- **Username:** `Admin` *(Case-sensitive, capital A)*
- **Password:** `zabbix`

---
*Note: Please ensure that port 8080 is available on your local machine before running the setup.*
